## 使用原则

- 这些图片是视觉参考，不是最终内容稿。
- 图片内文字默认不可信，最终标题、正文、标签必须由 HTML 重做。
- 强视觉页可以把图片作为背景板或主视觉板使用。
- 普通信息页和架构页不能整张图片直接作为最终页，需要提取构图、材质、色彩和组件语言后 HTML/SVG 重建。
